# Coffee Cafe

Eine responsive Café-Webseite, umgesetzt mit React und Vite. Die Seite stellt
Kaffeespezialitäten, Informationen zum Café und Kundenbewertungen vor.

## Funktionen

- Startseite mit Café-Einführung
- Übersicht der Kaffeespezialitäten
- Abschnitt über das Café
- Kundenbewertungen
- Navigation mit Sprunglinks zu den Seitenabschnitten
- Responsive Layout für Desktop, Tablet und Smartphone

## Voraussetzungen

- [Node.js](https://nodejs.org/) (empfohlen: aktuelle LTS-Version)
- npm (wird mit Node.js installiert)

## Lokal starten

1. Repository herunterladen oder klonen.
2. Im Projektordner ein Terminal öffnen.
3. Abhängigkeiten installieren:

   ```bash
   npm install
   ```

4. Entwicklungsserver starten:

   ```bash
   npm run dev
   ```

5. Die im Terminal angezeigte lokale Adresse im Browser öffnen.

## Weitere Befehle

Produktionsversion erstellen:

```bash
npm run build
```

Produktionsversion lokal ansehen:

```bash
npm run preview
```

Lint-Prüfung ausführen:

```bash
npm run lint
```

## Verwendete Technologien

- React

## Auf GitHub veröffentlichen

1. Auf [GitHub](https://github.com/) ein neues Repository erstellen. Wenn du
   bereits diese lokale README verwendest, beim Erstellen des Repositorys
   keine zusätzliche README-Datei anlegen.
2. Im Projektordner ein Terminal öffnen und diese Befehle ausführen. Ersetze
   `DEIN-BENUTZERNAME` durch deinen GitHub-Benutzernamen und
   `REPOSITORY-NAME` durch den Namen deines neuen Repositorys:

   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/DEIN-BENUTZERNAME/REPOSITORY-NAME.git
   git push -u origin main
   ```

3. Falls GitHub nach einer Anmeldung fragt, melde dich mit deinem GitHub-Konto
   an und folge den angezeigten Schritten.

Danach findest du den Projektcode auf der GitHub-Seite deines Repositorys.
